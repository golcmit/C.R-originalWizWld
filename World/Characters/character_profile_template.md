# キャラクタープロフィールひな型とリンクの貼り方

## キャラクタープロフィールひな型

このひな型は、キャラクターの情報を整理するためのものです。必要に応じて見出しを削除したり、追加したりして使ってください。

```markdown
# キャラクター名 (英語名)

## 概要

（キャラクターの簡単な説明）

## 基本情報

*   生年月日: YYYY年MM月DD日
*   血統: （純血、半純血、マグル生まれなど）
*   所属寮: （ホグワーツの寮名、または所属組織など）
*   愛称: （愛称があれば）
*   親: （親の名前、遺伝上の親など）
*   子供: （子供の名前）
*   配偶者: （配偶者の名前）
*   立場: （家での立場、組織での役割など）

## 経歴

（幼少期から現在までの主要な出来事）

### 幼少期
（幼少期の出来事）

### 学生時代
（学生時代の出来事）

## 活躍

（キャラクターの主な活躍や功績）

## 思想

（キャラクターの思想や信念）

## 能力と手口

（キャラクターの能力や、目的達成のための手段）

## 人間関係

*   （関係性の深いキャラクター名）: （そのキャラクターとの関係性）

## 最期

（キャラクターの最期、またはその可能性）

## （特定の時間軸や世界線での記述）

（例: ダームストラング世界線、ホグワーツ世界線など）

## 関連情報

*   （関連する概念や人物など）

## 備考

（その他特記事項）
```

## リンクの貼り方

ファイル内の他のキャラクターや関連情報へのリンクは、以下の形式で記述します。

`[[ファイルパス|表示テキスト]]`

*   **ファイルパス**: `World/` から始まる相対パスで指定します。プロジェクトのルートディレクトリからの相対パスです。
    *   例: `World/Linage/Fungsyun/History_o_Schiehallion` (これは `World/Linage/Fungsyun/History_o_Schiehallion.md` を指します)
    *   例: `World/Characters/Galina_Yuhtlahm_Fungsyun/profile` (これは `World/Characters/Galina_Yuhtlahm_Fungsyun/profile.md` を指します)
*   **表示テキスト**: リンクとして表示されるテキストです。ファイル名と異なるテキストを表示したい場合に指定します。
    *   例: `シェハリオン分家`
    *   例: `リーナ`

**使用例:**

*   `[[World/Linage/Fungsyun/History_o_Schiehallion|シェハリオン分家]]` → シェハリオン分家
*   `[[World/Characters/Galina_Yuhtlahm_Fungsyun/profile|リーナ]]` → リーナ
*   `[[World/Characters/Eustace_Thetisius_FitzArthur/profile|テティ]]` → テティ

ファイルパスのみを指定した場合もリンクとして機能しますが、表示テキストを指定することでより分かりやすいリンクになります。
